# 冷热搭子：开发文档

当前版本：0.4.0。随功能提交维护规则、验证记录、限制和变更历史；商用目标见 [ROADMAP.md](ROADMAP.md)。

## 产品与交付范围

原创明快几何风格的 2D 单人／本地双人合作闯关游戏。一个人切换两个搭子，两个人各控制一个搭子，笑点来自团建工单和一起翻车。当前交付 Godot 工程，非商业成品，不导出桌面二进制。

现有两条路径：六关固定教学与无限随机挑战。支持指定种子复现、三种配色、弹簧／桥梁／风场、关卡起点存档、音量与减少动态设置。后续优先验证合作乐趣和可靠性，再扩展内容。

## 运行环境

Godot 4.6.3 标准版，Compatibility 渲染，1152×720，canvas_items 缩放。无插件、账号、外部服务、.NET 或导出模板要求。Python 只用于开发工具，不是运行依赖。

导入 `project.godot` 后按 F5。继续使用现有隔离工作区，不需额外 Git worktree。

当前云机器用户目录不可写，可在开发命令前设置：

```sh
XDG_DATA_HOME=/workspace/.runtime/data \
XDG_CONFIG_HOME=/workspace/.runtime/config \
XDG_CACHE_HOME=/workspace/.runtime/cache \
godot --headless --path /workspace/LiGame --quit-after 120
```

这些覆盖是当前机器的可写路径选择，普通用户电脑不需要。`python3 tools/check.py` 自动创建独立临时目录，避免测试改动真实存档。

## 核心规则

1. 橙、蓝分别踩出生点右侧的同色踏板。每个踏板独立锁存，无需同时站住；两个都激活才开门。
2. 两人各收集两颗同色宝石，共四颗。
3. 门开启、宝石齐全、两人中心都在各自门框内，触发过关。
4. 1.8 秒后下一关；教学第六关显示完成菜单，可开始随机挑战。
5. 橙色免疫橙池，蓝色免疫蓝池，异色或紫池令整队回出生区。本关宝石、开门和桥梁保留；R 重开清空这些进度。
6. 两人互相穿过，避免单人被静止搭子阻挡。暂停、帮助、菜单期间不更新物理和局内计时。

设备：弹簧在地面接触时向上弹射；桥前匹配属性的角色踩开关后生成安全桥面；风场降低区域内有效下落加速度。桥梁和风场非通关必需，没有只能由未激活桥梁到达的必需宝石。

单人 A/D 或方向键移动，W/↑/空格跳跃，Tab 换人。双人橙 A/D/W、蓝方向键。手柄左摇杆／方向键、A 跳跃；单人手柄 X 换人，Start 暂停。M 切换模式，F1 帮助，Esc 暂停，F11 全屏，N 换种子回第一关。

## 架构

| 文件 | 责任 |
|---|---|
| `main.gd` | 游戏状态、场景生成、规则、菜单路由和关卡切换 |
| `scripts/buddy.gd` | CharacterBody2D 运动、100ms 离地宽容、120ms 跳跃缓冲、松键短跳 |
| `scripts/controls.gd` | 键盘与双手柄的 InputMap 配置、按角色读取输入 |
| `scripts/level_generator.gd` | 可复现的教学／随机关卡数据、机关、标题、提示、配色 |
| `scripts/game_view.gd` | 几何画面、紧凑 HUD、属性图案、角色动画和粒子；不修改碰撞规则 |
| `scripts/menu.gd` | 可鼠标／键盘操作的菜单和种子输入 |
| `scripts/save_store.gd` | 版本化关数存档、合法性检查、临时文件后替换 |
| `scripts/settings.gd` | 音量、全屏、减少动态的持久化 |
| `scripts/sounds.gd` | 六种运行时合成音效；无声 Dummy 驱动不创建播放任务 |

`.godot/` 是本机缓存，不提交。`.uid` 和字体 `.import` 是可复现工程元数据，可提交。用户存档不进入仓库。

## 随机与跳跃边界

教学使用固定种子 2000 加关数偏移，六个教学的布局不随冒险种子变化。随机模式使用 `seed + stage * 7919`。视觉粒子使用单独 RNG，不影响关卡生成。

每关四个区段，安全出生区和出口固定。池宽 65～90 px；平台高于地面 105～135 px，教学首关为 100 px。水平速度 245 px/s，初跳速度 720 px/s，重力 1450 px/s²：理论最大跳高约 179 px，同高水平跨度约 243 px。地面连续，区段之间有落脚空间。

弹簧初速度 850 px/s；风场附加向上加速度 900 px/s²，仍保留下落能力。机关帮助移动，不要求难以同步的双人输入。随机挑战尚无随关数增加的难度曲线，不能称为完整程序生成解谜系统。

## 存档与设置

`user://progress.cfg` 保存版本、关数、种子、单双人及教学／随机模式；继续从本关起点生成，宝石和踏板不跨退出保存。当前格式 v2，兼容读取 v1，视为随机模式。非法类型、超范围关数／种子和未知版本不作为有效进度载入。开始新冒险会替换上一段冒险进度。

`user://settings.cfg` 保存音量、减少动态和全屏，读取时验证类型和音量范围。写入使用同目录 `.tmp` 后替换。关数存档失败会提示且不阻断游玩；设置写入失败处理和损坏存档备份还可继续增强。

## 字体和许可

原创几何图形由代码绘制，音效运行时合成。Noto Sans CJK 子集采用 SIL OFL，保留 `assets/FONT-LICENSE.txt`。新增中文 UI 文案需要重建子集：

```sh
python3 tools/subset_font.py /path/to/NotoSansCJK-Regular.ttc
```

只在字体构建时需要 `fonttools`。脚本收集项目 GDScript 字符与基础 ASCII，再用 Godot 导入。不要将外部字体许可删掉或用未授权素材替换。

## 验证证据

当前在 Godot 4.6.3 Linux 上验证：

- `tests/smoke.gd`：416 项，角色、100 个种子的障碍范围、属性伤害、宝石、独立踏板、过关和实际跳跃等。
- `tests/systems.gd`：21 项，标题／暂停／帮助、存档、异常回退、手柄合成输入、跳跃机制。
- `tests/levels.gd`：21 项，教学稳定性、桥梁属性和碰撞、六关完成、合成音频、v1 存档迁移。
- `tests/preferences.gd`：14 项，音量与动态效果、设置读写、坏值、种子验证和返回菜单。
- `tests/traversal.gd`：10 次端到端通关，六关教学以及随机种子 0、42、12345、999999。使用真实按键、物理、重力和危险池，从出生点开门、收集到双出口；没有传送、伪造宝石或伤害豁免。
- `tests/capture.gd`：虚拟显示器＋Mesa 软件 OpenGL 渲染标题和游戏截图，人工检查中文、按钮、HUD 和画面位置；截图为 `docs/images/demo-v0.4.png`。

总计 472 项规则／系统检查和 10 次完整路径通关。单元规则测试会直接设置角色位置；完整通关测试不这样做。抽样完整通关不能证明任意种子全可解。音频检查验证生成数据及开关行为，没有真实扬声器听感测试。

一键执行 `python3 tools/check.py`：导入后逐项测试，检测退出码、引擎错误、非空测试摘要、断言失败和资源泄漏，不触碰用户真实存档。需要 Python 3 和 PATH 中的 Godot，也可传 Godot 绝对路径。

## 已知限制与风险

- 无真人完整试玩、真实手柄、音频设备和 Windows／macOS 验证。
- 同键盘双人可能遇到硬件多键冲突；手柄需要实机验证。
- 缺少按键重映射、联机、音乐、关卡选择、成绩系统和完整无障碍选项。
- 固定区段重复度仍高，桥梁可绕过，合作解谜深度和单人切换负担需要玩家反馈。
- 字体只包含当前文案字形，不支持任意中文输入。
- 未接 Steamworks 或商店页面，现有工程版本不是商用就绪证明。
