# 冷热搭子：开发文档

版本：0.2.0。本文随玩法和技术变更维护；每次功能提交同步更新变更记录、验证结果和已知限制。

## 目标与当前范围

面向未来 Steam 的轻量 2D 合作闯关游戏，支持一个人切换两个角色，以及两个人共用键盘。风格简单明快，失败轻松，笑点来自搭子一起翻车和离谱工单。当前目标是一个可直接在 Godot 中运行的原型，验证合作乐趣，不承诺销售收入。

本轮完成：单场景平台跳跃、橙蓝属性、双人踏板、宝石收集、双出口、受限随机地图、自动下一关、无限复活、中文说明与吐槽、键盘单／双人模式。

## 核心循环

1. 在安全出生区准备，默认单人，通过 Tab 轮流控制两个角色。
2. 橙蓝各踩一次 x=116 和 x=175 的同色踏板。各踏板独立永久锁存，无需同时站住；两个都激活后开门。顶部显示踏板、剩余宝石和出口到达状态。
3. 各自收集两颗同色宝石。危险池同属性免疫，异属性和紫色池触发整队复活。
4. 门开启、四颗宝石收齐、两人分别站到对应出口，才算成功。
5. 显示成功提示，1.8 秒后开始下一关。N 更换冒险种子并回到第一关，R 保留种子和关数但清空本关进度。

死亡保留宝石和机关，降低原型重试成本。角色互相穿过，避免单人模式被队友挡路。切换模式保留当前进度。

## 随机生成与难度边界

关卡使用 `seed_number + stage * 7919` 驱动独立 RandomNumberGenerator，相同种子和关数重现相同布局。生成四段危险池及上方平台，随机化横向偏移、平台高度、池宽和属性；出生区、踏板和出口固定安全。

目前水平速度 245 px/s，跳跃初速度 720 px/s，重力 1450 px/s²，理论跳高约 179 px，回到同一高度约 0.99 秒，水平距离约 243 px。平台高于地面 105～145 px，池宽 65～95 px。地面连续，玩家可以落地后再次起跳，不依赖连续平台跳跃。自动化范围检查用于排查明显超出能力的布局，不能替代真实玩家对所有随机地图的通关测试。

当前没有随关数增长的难度曲线；四个模块和机关结构相同。下一阶段应扩充有解的手工模块池，按难度组合，再添加路径求解和大量种子的实际运动验证。

## 架构与约定

- `project.godot`：Godot 4.6.3，1152×720，canvas_items 缩放，Compatibility 渲染。
- `main.tscn`：Node2D 入口。
- `main.gd`：流程与关卡目标、即时绘图；`generate()` 重建关卡。
- `scripts/buddy.gd`：角色运动，100ms 离地宽容、120ms 跳跃缓冲、松键短跳。
- `scripts/controls.gd`：键盘及双手柄动作映射。
- `scripts/menu.gd`：可键盘／鼠标操作的标题、暂停和帮助界面。
- `scripts/save_store.gd`：版本化 ConfigFile 存档、类型和范围验证、临时文件写入后替换。
- `assets/ui-font.otf`：Noto Sans CJK 的所需字形子集，内嵌避免玩家电脑缺少中文字体。新增文案若出现缺字，需要扩大字体子集；随附上游 OFL 许可。
- `tests/smoke.gd`：SceneTree 测试运行器，有断言和失败退出状态。
- `.godot/` 为本机缓存，不提交；无需第三方插件或环境变量。

已拆分角色、输入、菜单与存档；下一步拆出关卡生成并增加可验证模块。每次功能修改先更新文档，再执行相关测试。使用现有隔离工作区，不需要额外 Git worktree。

命令：

```sh
cd /workspace/LiGame
godot --headless --editor --import --quit
godot --headless --quit-after 120
godot --headless --script tests/smoke.gd
```

在当前云环境，用户目录不可写时，在命令前设置 `XDG_DATA_HOME=/workspace/.runtime/data XDG_CONFIG_HOME=/workspace/.runtime/config XDG_CACHE_HOME=/workspace/.runtime/cache`。普通本机无需设置。

## 已知限制

- 暂无音效、音乐、按键重映射和完整无障碍设置。
- 已支持手柄动作映射，测试使用合成输入，尚需真实设备验证；同键盘双人可能受多键冲突影响。
- 字体仅覆盖当前界面所用字形；不支持任意中文输入。
- 随机化变化仍小，机关只有一种，不含敌人、Boss 或复杂关卡解谜。
- 几何角色、美术和吐槽均为原型表达，需要真实玩家评估辨识度和幽默效果。
- 未集成 Steamworks，不包含商店页、成就、云存档、收费或盈利保证。
