# 冷热搭子 · 摸鱼闯关队

一个用 **Godot 4.6.3** 制作的原创 2D 单人／本地双人合作闯关 Demo。橙蓝搭子一起踩机关、收宝石、跳过危险池，在随机生成的小关卡里反复“上班”和“翻车”。

## 下载与运行

[下载 Godot 工程 ZIP](https://github.com/2584911836/LiGame/archive/refs/heads/main.zip)

1. 下载并解压工程，安装 Godot **4.6.3 标准版**，无需 .NET。
2. 在 Godot 项目管理器点击“导入”，选择 `project.godot`。
3. 首次导入等待字体资源处理完成，按 **F6/F5** 开始游戏。

不需要安装插件、导出模板、素材包、账号或联网服务。当前只交付 Godot 工程，不交付 Windows／Linux 成品。

## v0.3 更新

- 六关固定教学：搭子入职、弹簧加班、搭桥摸鱼、风里打卡、离谱团建、下班考核。
- 独立随机挑战：弹簧、同色开关桥梁、减缓下落风场随机组合，三套主题配色。
- 基础合成音效，可在暂停菜单开关；无需额外音频素材。
- 老版存档继续有效，自动作为随机挑战读取。
- 完整路径机器人通过六关教学和四个随机种子，真实输入完成跳跃、收集和双人过关。

## v0.2 更新

新增标题、暂停、帮助菜单和本关起点存档。首次进入先选择“单人出发”或“双人同屏”；Esc 暂停，F1 帮助，F11 全屏。

手柄支持：第一个手柄控制橙色，第二个控制蓝色；单人用第一个手柄控制当前搭子。左摇杆／方向键移动，A 跳跃，X 切换搭子，Start 暂停。手柄仅经过模拟输入验证，仍需实机兼容性测试。

跳跃支持离地宽容时间、落地前输入缓冲和松键短跳。两名角色可以穿过彼此。自动保存关数、种子和模式，退出后选择“继续冒险”从本关起点开始；本关宝石和踏板不跨退出保存。

## 操作

| 操作 | 单人模式（默认） | 双人同屏模式 |
|---|---|---|
| 移动 | A / D 或 ← / → | 橙色 A / D，蓝色 ← / → |
| 跳跃 | W / ↑ / 空格 | 橙色 W，蓝色 ↑ |
| 切换角色 | Tab | 两人分别控制，无需切换 |
| 切换单／双人 | M | M |
| 重开当前关 | R | R |
| 新的随机冒险 | N | N |

先让橙蓝角色各踩一次出生点右边的同色踏板（无需同时站住），出口便会保持开启。踏板下方会显示“已踩”，顶部会显示尚未完成的过关条件。收齐平台上的四颗同色宝石，再让两人进入右侧各自颜色的出口，即可自动进入下一关。

橙色角色免疫橙色池，蓝色角色免疫蓝色池，紫色池对双方都有伤害。翻车时两人一起回到起点，但保留本关宝石和已开启的门；重开本关则全部重置。没有生命限制。

## 开发与验证

- [开发文档](docs/DEVELOPMENT.md)：设计、架构、阶段计划、已知限制和变更记录。
- 无头启动：`godot --headless --path . --quit-after 120`
- 机关验证：`godot --headless --path . --script tests/levels.gd`
- 完整通关：`godot --headless --fixed-fps 60 --path . --script tests/traversal.gd`
- 系统验证：`godot --headless --path . --script tests/systems.gd`
- 自动化冒烟测试：`godot --headless --path . --script tests/smoke.gd`
- `main.gd` 为流程、规则与即时绘图；`scripts/` 包含角色运动、输入、菜单、存档；`main.tscn` 为入口场景。

目前是玩法验证原型，尚未达到 Steam 商业发布标准。随机地图采用固定骨架上的受限随机布局，不是复杂迷宫；暂不包含联机、按键重映射或完整音乐。原创几何画面不使用《森林冰火人》的名称、美术、地图或代码。
